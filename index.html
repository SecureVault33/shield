Questions fréquentes sur le chiffrement de fichiers Windows

Quelle est la différence entre verrouillage et chiffrement de fichiers ?

Le mode Rapide bloque l'accès au fichier sans le modifier — comme fermer une porte à clé. Le mode Fort chiffre entièrement le contenu avec AES-256-GCM — même un vol physique du disque dur ne compromet pas vos données.

Que se passe-t-il si j'oublie mon mot de passe ?

En mode Rapide, le déverrouillage forcé (via le Master Password) permet de récupérer l'accès. En mode Fort, collez votre clé de récupération dans le champ mot de passe — SecureVault la détecte automatiquement.

SecureVault ralentit-il mon ordinateur Windows ?

Non. SecureVault ne tourne pas en arrière-plan. Il ne s'active que lorsque vous l'utilisez depuis le menu clic droit ou le Centre d'administration. L'exécutable pèse moins de 10 Mo.

Mes fichiers chiffrés sont-ils envoyés sur internet ?

Jamais. Tout le traitement (verrouillage, chiffrement, déchiffrement) se fait localement sur votre machine. Vos données ne quittent jamais votre ordinateur. La seule connexion internet est une activation unique de la licence Pro — aucune donnée personnelle ou fichier n'est transmis.

SecureVault est-il compatible avec mon antivirus ?

Oui. Lors du premier lancement, votre antivirus peut signaler SecureVault car il modifie les permissions de fichiers — c'est normal et sans risque. Ajoutez SecureVault en exception. Le code source de la version gratuite est disponible sur GitHub pour vérification.

La licence Pro fonctionne-t-elle sur plusieurs PC ?

Chaque licence Pro est liée à un seul poste. Si vous changez d'ordinateur, désactivez la licence sur l'ancien et réactivez la même clé sur le nouveau — aucun contact support nécessaire. Les clés sont gérées automatiquement par LemonSqueezy.

SecureVault fonctionne-t-il sur Windows Home ?

Oui, SecureVault fonctionne sur toutes les éditions de Windows 10 et Windows 11, y compris Home. Contrairement à BitLocker qui nécessite Windows Pro, SecureVault est accessible à tous les utilisateurs Windows.

Le chiffrement AES-256 est-il vraiment sûr ?

AES-256-GCM est le standard utilisé par les gouvernements et les armées du monde entier. Combiné avec Argon2id pour la dérivation de clé, il est résistant aux attaques par force brute, même avec les supercalculateurs actuels.
