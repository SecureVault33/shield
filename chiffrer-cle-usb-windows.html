Comment Chiffrer une Cle USB sur Windows Gratuitement

25 septembre 2026 ⏱ Lecture : 7 min

Chaque annee, des millions de cles USB sont perdues ou oubliees dans les transports, les bureaux et les lieux publics. Selon une etude du Ponemon Institute, plus de 22 000 cles USB sont oubliees chaque annee rien que dans les pressings americains. Sans chiffrement, toute personne qui retrouve votre cle USB peut lire l'integralite de vos donnees : documents de travail, photos personnelles, fichiers bancaires, mots de passe enregistres.

Que vous souhaitiez chiffrer une cle USB sur Windows, proteger un disque dur externe ou simplement securiser quelques fichiers sensibles avant de les transporter, ce guide vous presente trois methodes gratuites qui fonctionnent sur Windows 10 et Windows 11, y compris l'edition Famille.

Pourquoi chiffrer votre cle USB est essentiel

Les supports amovibles sont, par nature, les plus exposes au vol et a la perte. Contrairement a votre disque dur interne, une cle USB voyage avec vous et peut disparaitre a tout moment.

  • Perte et vol : Une etude de Kingston Technology revele que 71 % des employes ont deja perdu une cle USB contenant des donnees professionnelles. Sans chiffrement, ces donnees sont accessibles en quelques secondes.
  • Obligations RGPD : Pour les professionnels, transporter des donnees personnelles de clients ou de patients sur un support non chiffre constitue une infraction au RGPD. Les amendes peuvent atteindre 4 % du chiffre d'affaires annuel.
  • Donnees personnelles : Photos de famille, copies de pieces d'identite, releves bancaires, declarations fiscales... Une cle USB perdue peut donner acces a suffisamment d'informations pour une usurpation d'identite.

A retenir : Le chiffrement transforme vos fichiers en donnees illisibles sans le mot de passe. Meme si votre cle USB tombe entre de mauvaises mains, vos donnees restent protegees.

Methode 1 — Chiffrer des fichiers sur cle USB avec SecureVault

SecureVault permet de chiffrer des fichiers individuels directement sur votre cle USB, ou de les chiffrer sur votre PC avant de les copier sur le support amovible. C'est la methode la plus simple et la plus rapide : un clic droit, un mot de passe, et vos fichiers sont proteges par un chiffrement AES-256-GCM.

Comment proceder

  1. Installez SecureVault depuis le site officiel. L'installation prend quelques secondes et ajoute une option dans le menu contextuel de l'Explorateur Windows.
  2. Branchez votre cle USB et ouvrez-la dans l'Explorateur de fichiers. Selectionnez les fichiers ou dossiers a proteger.
  3. Clic droit > Chiffrer avec SecureVault. Choisissez un mot de passe robuste (12 caracteres minimum, melange de majuscules, minuscules, chiffres et symboles).
  4. Vos fichiers sont chiffres au format .vault. Vous pouvez supprimer les originaux non chiffres de la cle USB en toute securite.

Pour dechiffrer, le destinataire installe SecureVault (gratuit), fait un clic droit sur le fichier .vault et saisit le mot de passe. Communiquez toujours le mot de passe par un canal separe (telephone, messagerie chiffree).

Avantage cle : SecureVault fonctionne sur toutes les editions de Windows, y compris Windows Famille. Pas besoin de Windows Pro ni d'un module TPM. Vous chiffrez fichier par fichier, ce qui est ideal pour proteger uniquement les documents sensibles de votre cle USB sans chiffrer l'integralite du support. Pour en savoir plus sur le chiffrement de fichiers, consultez notre guide complet du chiffrement de fichiers sur Windows.

Methode 2 — BitLocker To Go (Windows Pro uniquement)

BitLocker To Go est la solution native de Microsoft pour chiffrer un disque dur externe ou une cle USB. Elle chiffre l'integralite du support amovible avec un mot de passe ou une cle de recuperation.

Etapes pour activer BitLocker To Go

  1. Branchez votre cle USB ou disque dur externe sur votre PC Windows.
  2. Ouvrez l'Explorateur de fichiers, faites un clic droit sur la cle USB, puis selectionnez Activer BitLocker.
  3. Choisissez « Utiliser un mot de passe » pour deverrouiller le lecteur. Saisissez un mot de passe robuste.
  4. Sauvegardez la cle de recuperation (fichier, compte Microsoft ou impression). Cette cle est indispensable si vous oubliez votre mot de passe.
  5. Choisissez « Chiffrer tout le lecteur » pour proteger egalement les fichiers precedemment supprimes, puis lancez le chiffrement.

Limitations importantes :

  • Windows Pro ou Entreprise requis pour activer le chiffrement. Les utilisateurs de Windows Famille ne peuvent pas chiffrer une cle USB avec BitLocker.
  • Le dechiffrement sur un autre PC necessite egalement Windows (pas de compatibilite macOS ou Linux native).
  • Le chiffrement porte sur l'ensemble du support : vous ne pouvez pas chiffrer uniquement certains fichiers.

BitLocker To Go reste une bonne option si vous utilisez Windows Pro et que vous souhaitez une protection transparente sur l'integralite de votre cle USB. Pour les utilisateurs de Windows Famille, il faudra se tourner vers SecureVault ou VeraCrypt.

Methode 3 — VeraCrypt : creer un volume chiffre sur cle USB

VeraCrypt est un logiciel de chiffrement open source qui permet de creer un conteneur chiffre directement sur votre cle USB. C'est une methode puissante, adaptee aux utilisateurs a l'aise avec les outils techniques.

Comment creer un volume chiffre sur cle USB

  1. Telechargez et installez VeraCrypt depuis le site officiel (veracrypt.fr). Vous pouvez aussi utiliser le mode portable : extrayez VeraCrypt directement sur la cle USB pour l'utiliser sans installation.
  2. Lancez VeraCrypt et cliquez sur Creer un volume. Choisissez « Creer un fichier conteneur chiffre » et selectionnez un emplacement sur votre cle USB.
  3. Configurez le chiffrement : selectionnez l'algorithme AES (ou une cascade AES-Twofish-Serpent pour les plus exigeants), definissez la taille du conteneur et choisissez un mot de passe.
  4. Montez le volume dans VeraCrypt pour y acceder comme un lecteur virtuel. Copiez vos fichiers sensibles dans ce lecteur, puis demontez le volume lorsque vous avez termine.

Avantages : chiffrement robuste, mode portable sur cle USB, gratuit et open source, fonctionne sur toutes les editions de Windows.

Inconvenients : la procedure est plus complexe que SecureVault ou BitLocker. Le conteneur a une taille fixe definie a la creation. Le destinataire doit installer VeraCrypt ou disposer de la version portable pour acceder aux fichiers. Pour une analyse plus poussee, consultez notre guide de protection sans BitLocker.

Conseils pour proteger vos supports amovibles

Quelle que soit la methode de chiffrement choisie, adoptez ces bonnes pratiques pour securiser vos cles USB et disques externes :

  • Chiffrez avant de copier : Prenez l'habitude de chiffrer vos fichiers sensibles avant de les transferer sur une cle USB. Une fois les donnees copiees en clair, des traces peuvent subsister meme apres suppression.
  • Utilisez un mot de passe robuste : Au moins 12 caracteres, avec un melange de majuscules, minuscules, chiffres et symboles. Evitez les mots du dictionnaire et les informations personnelles. Un gestionnaire de mots de passe (Bitwarden, KeePass) peut vous aider.
  • Conservez une sauvegarde : Ne stockez jamais l'unique copie d'un fichier important sur une cle USB. Gardez toujours une sauvegarde chiffree sur votre PC ou dans un stockage cloud securise.
  • Identifiez vos cles USB : Etiquetez vos cles avec un numero ou un nom (sans reveler le contenu) pour les retrouver plus facilement et savoir rapidement quelle cle contient quoi.

Pour approfondir les bonnes pratiques de chiffrement, consultez notre article sur le fonctionnement du chiffrement AES-256.

FAQ — Chiffrer une cle USB sur Windows

Peut-on chiffrer une cle USB sur Windows Famille (Home) ?

Oui, mais pas avec BitLocker, qui est reserve aux editions Pro et Entreprise. Sur Windows Famille, vous pouvez utiliser SecureVault pour chiffrer les fichiers stockes sur votre cle USB, ou VeraCrypt pour creer un volume chiffre sur la cle. Les deux logiciels sont gratuits et fonctionnent sur toutes les editions de Windows.

Mon correspondant peut-il lire les fichiers chiffres sur la cle USB ?

Cela depend de la methode utilisee. Avec SecureVault, le destinataire doit installer SecureVault (gratuit) et connaitre le mot de passe pour dechiffrer les fichiers .vault. Avec BitLocker To Go, l'autre ordinateur doit tourner sous Windows. Avec VeraCrypt, le destinataire doit installer VeraCrypt ou utiliser le mode portable disponible sur la cle.

Le chiffrement ralentit-il les transferts sur cle USB ?

Avec SecureVault, le chiffrement est ponctuel : vous chiffrez un fichier en quelques secondes avant de le copier, sans impact sur la vitesse de transfert USB. Avec BitLocker To Go, le chiffrement en temps reel peut legerement ralentir les ecritures, surtout sur les cles USB 2.0. Avec VeraCrypt, les performances dependent de la vitesse de la cle et de l'algorithme choisi. Les processeurs modernes avec instructions AES-NI minimisent cet impact.
