Proteger un Dossier par Mot de Passe sur Windows 10/11 — Guide 2026

Vos documents confidentiels, photos personnelles ou fichiers professionnels sont-ils vraiment en securite sur votre PC ? Decouvrez 4 methodes concretes pour proteger un dossier par mot de passe sur Windows 10 et Windows 11.

Que vous partagiez un ordinateur familial, travailliez dans un espace de coworking ou souhaitiez simplement garder vos donnees personnelles a l'abri des regards indiscrets, proteger un dossier par mot de passe sur Windows est devenu indispensable en 2026.

Pourtant, Windows ne propose toujours pas de fonction native simple pour verrouiller un dossier individuel avec un mot de passe. Pas de clic droit magique, pas d'option dans les proprietes du dossier. C'est frustrant, mais la bonne nouvelle est qu'il existe plusieurs solutions fiables.

Dans ce guide, nous allons comparer 4 methodes pour securiser vos dossiers sous Windows, de la plus simple (un clic droit) a la plus technique (BitLocker). Vous trouverez des tutoriels pas a pas, un tableau comparatif et une FAQ pour vous aider a choisir la solution adaptee a vos besoins.

Mots-cles couverts dans ce guide : proteger dossier mot de passe Windows, verrouiller dossier Windows 10, chiffrer dossier Windows 11, mot de passe dossier PC, securiser fichiers Windows, crypter dossier Windows gratuit.

Solution 1 — SecureVault : verrouiller un dossier en un clic droit

SecureVault est un outil concu pour proteger vos dossiers par mot de passe sur Windows de la maniere la plus simple possible. Il s'integre directement dans le menu contextuel de l'Explorateur de fichiers : un clic droit sur n'importe quel dossier suffit pour le verrouiller.

SecureVault propose deux modes de protection complementaires, adaptes a differents niveaux de securite :

Mode Quick Lock — Verrouillage instantane

Le mode Quick Lock utilise les permissions NTFS (listes de controle d'acces, ou ACL) pour bloquer immediatement l'acces a un dossier. En un instant, le dossier devient inaccessible a tous les utilisateurs de la machine, y compris ceux qui disposent d'un compte administrateur standard.

  • Instantane : le verrouillage et le deverrouillage se font en une fraction de seconde, quelle que soit la taille du dossier.
  • Aucune modification des fichiers : vos donnees ne sont pas deplacees ni transformees. Seules les permissions d'acces changent.
  • Ideal pour un usage quotidien : protegez rapidement un dossier avant de quitter votre poste ou de preter votre PC.

A savoir : le mode Quick Lock offre une excellente protection au quotidien. Cependant, un utilisateur ayant un acces physique au disque dur (par exemple en le retirant de l'ordinateur) pourrait theoriquement contourner les permissions NTFS. Pour une protection maximale, privilegiez le mode Strong.

Mode Strong — Chiffrement AES-256

Le mode Strong va beaucoup plus loin en appliquant un chiffrement AES-256 complet a l'ensemble du contenu du dossier. Il s'agit du meme standard de chiffrement utilise par les agences gouvernementales et les institutions financieres.

  • Protection totale : meme si quelqu'un retire physiquement votre disque dur, les fichiers restent illisibles sans le mot de passe.
  • Chiffrement de bout en bout : chaque fichier est individuellement chiffre avec AES-256.
  • Irreversible sans mot de passe : personne ne peut acceder a vos donnees sans la cle de dechiffrement.

Pour en savoir plus sur le chiffrement de fichiers, consultez notre guide : Comment chiffrer un fichier sur Windows.

Tutoriel : proteger un dossier avec SecureVault

  1. Telechargez et installez SecureVault depuis le lien ci-dessous. L'installation prend moins de 30 secondes.
  2. Faites un clic droit sur le dossier que vous souhaitez proteger dans l'Explorateur de fichiers Windows.
  3. Selectionnez « SecureVault » dans le menu contextuel, puis choisissez le mode de protection : Quick Lock pour un verrouillage rapide ou Strong pour un chiffrement complet.

Solution 2 — Creer un dossier compresse protege (7-Zip)

7-Zip est un logiciel de compression gratuit et open source qui permet de creer des archives protegees par mot de passe. C'est une alternative viable si vous souhaitez proteger un dossier par mot de passe sans installer un outil dedie a la securite.

Comment faire

  1. Installez 7-Zip depuis le site officiel si ce n'est pas deja fait.
  2. Faites un clic droit sur le dossier a proteger, puis selectionnez 7-Zip > Ajouter a l'archive.
  3. Choisissez le format 7z et la methode de chiffrement AES-256. Entrez un mot de passe robuste dans les champs prevus.
  4. Cochez « Chiffrer les noms de fichiers » pour masquer egalement la structure du dossier.
  5. Supprimez le dossier original une fois l'archive creee (sinon les fichiers restent accessibles en clair).

Limites de cette methode

Inconvenients : cette methode cree une copie compresse de vos fichiers. Vous devez supprimer manuellement les originaux. De plus, chaque fois que vous souhaitez acceder a un fichier, il faut decompresser l'archive, modifier le fichier, puis recreer l'archive. Ce processus est lent et peu pratique pour un usage quotidien, surtout avec de gros dossiers.

7-Zip reste une bonne solution pour archiver et proteger des fichiers que vous n'avez pas besoin de consulter frequemment, comme des sauvegardes ou des documents fiscaux anciens.

Solution 3 — Utiliser BitLocker (Windows Pro uniquement)

BitLocker est la solution de chiffrement integree a Windows. Elle permet de chiffrer un lecteur entier (disque dur, SSD, cle USB) avec une protection par mot de passe.

Cependant, BitLocker presente une limitation majeure : il n'est disponible que sur les editions Windows Pro, Enterprise et Education. Si vous utilisez Windows Home (la version la plus repandue chez les particuliers), cette option n'est tout simplement pas accessible.

Comment activer BitLocker

  1. Ouvrez l'Explorateur de fichiers et faites un clic droit sur le lecteur que vous souhaitez chiffrer.
  2. Selectionnez « Activer BitLocker ».
  3. Choisissez la methode de deverrouillage : mot de passe ou cle USB.
  4. Sauvegardez votre cle de recuperation (sur votre compte Microsoft, sur une cle USB ou en l'imprimant). Cette cle est indispensable en cas d'oubli du mot de passe.
  5. Lancez le chiffrement. Le processus peut prendre plusieurs heures selon la taille du disque.

Important : BitLocker chiffre des lecteurs entiers, pas des dossiers individuels. Si vous souhaitez proteger un seul dossier, vous devez creer un disque virtuel (VHD), le monter, y placer vos fichiers, puis activer BitLocker sur ce disque virtuel. Cette manipulation est complexe pour la plupart des utilisateurs.

Solution 4 — Masquer un dossier (solution basique)

Windows permet de rendre un dossier « invisible » en modifiant ses attributs. C'est la methode la plus simple, mais aussi la moins securisee.

  1. Faites un clic droit sur le dossier et selectionnez Proprietes.
  2. Cochez l'option « Cache » dans l'onglet General.
  3. Cliquez sur Appliquer, puis choisissez d'appliquer a tous les sous-dossiers et fichiers.

Attention : ce n'est PAS une vraie protection. N'importe quel utilisateur peut afficher les fichiers caches en cochant « Elements masques » dans l'onglet Affichage de l'Explorateur. Il n'y a aucun mot de passe, aucun chiffrement. Cette methode ne fait que masquer visuellement le dossier et ne doit jamais etre utilisee pour des donnees sensibles.

Masquer un dossier peut suffire pour cacher une surprise d'anniversaire, mais certainement pas pour proteger des documents confidentiels, des donnees bancaires ou des fichiers professionnels.

Le mode Quick Lock modifie les permissions NTFS (ACL) du dossier pour en bloquer l'acces. C'est instantane et ne modifie pas les fichiers eux-memes. Le mode Strong applique un chiffrement AES-256 a chaque fichier du dossier. Meme si quelqu'un retire votre disque dur et le connecte a un autre PC, vos donnees restent totalement illisibles sans le mot de passe.

Oui. AES-256 (Advanced Encryption Standard avec une cle de 256 bits) est le standard de chiffrement le plus robuste actuellement disponible. Il est utilise par les gouvernements, les banques et les armees du monde entier. Avec la technologie actuelle, il faudrait des milliards d'annees a un superordinateur pour forcer une cle AES-256 par force brute.

Pour le mode Quick Lock, vous pouvez deverrouiller le dossier depuis l'interface SecureVault avec votre mot de passe maitre. Pour le mode Strong (chiffrement AES-256), il est techniquement impossible de recuperer les fichiers sans le mot de passe. C'est la force du chiffrement : meme les developpeurs de SecureVault ne peuvent pas contourner cette protection. Nous vous recommandons vivement de conserver votre mot de passe dans un gestionnaire de mots de passe securise.
