1. Introduction

SecureVault est un outil léger pour Windows qui protège vos fichiers et dossiers directement depuis le menu contextuel de l'Explorateur — un clic droit suffit pour verrouiller ou chiffrer n'importe quel élément, sans quitter votre flux de travail.

🔒 Mode Rapide

Bloque l'accès à un fichier ou dossier en modifiant ses permissions Windows (NTFS). C'est instantané et pratique pour un usage quotidien — masquer un dossier des regards indiscrets sur votre propre ordinateur.

🛡️ Mode Fort

Chiffre réellement le contenu avec l'algorithme AES-256-GCM. Le fichier original est remplacé par une version chiffrée illisible sans le mot de passe. C'est la protection à utiliser pour vos données réellement sensibles.

2. Installation

Lancer l'installeur

Double-cliquez sur SecureVault_Setup.exe et suivez l'assistant. L'installation ajoute automatiquement le sous-menu SecureVault au clic droit de l'Explorateur ainsi qu'un raccourci dans le menu Démarrer.

Le Master Password

Au premier lancement, SecureVault vous demande de créer un Master Password. Ce mot de passe unique n'a qu'un seul rôle : permettre le déverrouillage forcé d'un fichier en Mode Rapide si vous perdez son mot de passe individuel ou si le fichier devient inaccessible.

À retenir Choisissez un Master Password fort et mémorisable — il n'est jamais affiché après sa création. Il ne déchiffre pas les fichiers en Mode Fort (voir la section Sécurité).

3. Utilisation quotidienne

Toutes les actions se font depuis le clic droit de l'Explorateur Windows :

📁 Mon dossier confidentiel
   └── Clic droit
        └── 🛡️ SecureVault ▸
             ├── 🔒 Verrouiller (Rapide)
             ├── 🔓 Déverrouiller
             ├── 🛡️ Chiffrer (Fort)
             ├── 🔑 Déchiffrer
             └── 📊 Centre d'administration

Verrouiller un fichier ou dossier

  1. Clic droit sur l'élément → SecureVault → Verrouiller (Rapide)
  2. Choisissez un mot de passe pour cet élément
  3. L'élément devient inaccessible et un fichier compagnon .securevault apparaît à côté

Déverrouiller

Deux façons : clic droit → SecureVault → Déverrouiller, ou double-clic directement sur le fichier .securevault qui l'accompagne. Le mot de passe utilisé au verrouillage vous sera demandé.

Chiffrer un fichier ou dossier

  1. Clic droit sur l'élément → SecureVault → Chiffrer (Fort)
  2. Choisissez un mot de passe (une barre de force vous guide)
  3. Une recovery key s'affiche une seule fois — notez-la immédiatement
  4. Un fichier .vault est créé ; vous pouvez choisir de supprimer l'original de façon sécurisée (3 passes d'écrasement)

Déchiffrer

Clic droit sur le fichier .vault → SecureVault → Déchiffrer, puis entrez le mot de passe utilisé au chiffrement.

Mot de passe perdu ? Utilisez la recovery key Pour déchiffrer avec la recovery key, collez-la dans le champ mot de passe. SecureVault la détecte automatiquement. Le mot de passe et la recovery key ouvrent chacun le fichier, indépendamment l'un de l'autre.
Fichiers chiffrés avant la version 1.0.1 Leur recovery key n'est pas utilisable : seul le mot de passe fonctionne. SecureVault le signale au moment du déchiffrement. Déchiffrez-les puis chiffrez-les à nouveau pour obtenir une recovery key réellement utilisable.

4. Centre d'administration (Dashboard)

Y accéder

Trois façons d'ouvrir le dashboard :

  • Tapez « SecureVault » dans la recherche Windows
  • Clic droit n'importe où dans l'Explorateur → SecureVault → 📊 Centre d'administration
  • Lancez securevault.exe sans argument, ou avec dashboard

La liste des fichiers protégés

L'onglet 📋 Fichiers protégés liste tout ce que SecureVault a verrouillé ou chiffré, avec son mode, sa date et son statut. Sélectionnez une ou plusieurs lignes pour déverrouiller, déchiffrer ou retirer des entrées de la liste.

Le déverrouillage forcé

Réservé aux situations d'urgence en Mode Rapide uniquement (mot de passe perdu, fichier bloqué) : la zone orange « Déverrouillage forcé » demande votre Master Password puis reprend les permissions du fichier, avec élévation administrateur si nécessaire.

Ne fonctionne pas en Mode Fort Le déverrouillage forcé ne peut rien pour un fichier chiffré : sans le mot de passe ou la recovery key, les données restent définitivement illisibles — c'est voulu.

Les paramètres

L'onglet ⚙️ Paramètres permet d'ajuster le rappel de sécurité, de changer votre Master Password, de choisir le thème et de définir le dossier d'export des recovery keys.

Changer le Master Password re-chiffre automatiquement toutes vos recovery keys enregistrées. Le changement de thème relance le Centre d'administration pour s'appliquer.

L'export des recovery keys

Le bouton 📥 Exporter les recovery keys génère un fichier texte récapitulant toutes vos clés de récupération enregistrées, après vérification du Master Password. Imprimez ce fichier et conservez-le en lieu sûr, puis supprimez la copie numérique.

5. Sécurité — Ce qu'il faut savoir

ModeProtège contreNe protège pas contre
🔒 Rapide L'accès accidentel ou occasionnel (partage d'ordinateur, curiosité) Un attaquant déterminé ayant un accès administrateur à la machine
🛡️ Fort Tout accès non autorisé — protection cryptographique complète La perte du mot de passe et de la recovery key (données perdues à jamais)
Le Master Password ne déverrouille pas les fichiers chiffrés Il ne sert qu'au déverrouillage forcé en Mode Rapide. En Mode Fort, seuls le mot de passe du fichier ou sa recovery key permettent de récupérer les données.

Les limites, en toutes lettres

Le Mode Rapide est une barrière, pas un coffre-fort Il protège contre l'accès accidentel. Un administrateur déterminé peut reprendre possession des fichiers via le déverrouillage forcé — c'est d'ailleurs exactement ce que fait SecureVault lui-même quand vous avez perdu votre mot de passe. Pour une protection cryptographique réelle, utilisez le Mode Fort.
La suppression sécurisée n'efface pas tout sur un SSD Les 3 passes d'écrasement sont efficaces sur les disques durs traditionnels (HDD). Sur les SSD, le wear leveling répartit les écritures sur des cellules physiques différentes : des copies des données d'origine peuvent subsister dans des zones inaccessibles au système. Pour une destruction garantie sur SSD, chiffrez le fichier (Mode Fort) plutôt que de compter sur l'effacement de l'original.
Vos recovery keys dépendent de votre Master Password Depuis la version 0.7.0, les recovery keys enregistrées par SecureVault sont chiffrées sur votre disque avec votre Master Password. Si vous perdez votre Master Password et votre fichier d'export, ces recovery keys sont irrécupérables — et avec elles, le dernier recours pour vos fichiers chiffrés dont vous auriez aussi oublié le mot de passe.

Recommandations

  • Imprimez vos recovery keys ou stockez-les hors ligne, jamais uniquement dans un fichier numérique
  • Utilisez un mot de passe fort et unique pour chaque fichier chiffré important
  • Gardez votre Master Password mémorisable mais difficile à deviner — il protège l'accès d'urgence à tous vos fichiers en Mode Rapide

6. FAQ

Version gratuite ou SecureVault Pro ?

Cette version gratuite permet 20 verrouillages et 3 chiffrements. Déverrouiller et déchiffrer restent toujours gratuits et illimités. Pour un usage illimité, SecureVault Pro est disponible sur securevault-app.com (lien Passer à Pro → du Centre d'administration).

J'ai perdu mon mot de passe, que faire ?

Mode Rapide : utilisez le déverrouillage forcé depuis le dashboard (Master Password requis). Mode Fort : seule la recovery key permet de récupérer le fichier : lancez le déchiffrement et collez-la dans le champ mot de passe. Sans elle, les données sont définitivement perdues. Vous ne l'avez pas notée ? Si vous l'avez enregistrée, retrouvez-la avec 📥 Exporter les recovery keys (Master Password requis). Attention : pour un fichier chiffré avant la version 1.0.1, la recovery key n'ouvre rien.

Le fichier a disparu après verrouillage, où est-il passé ?

Il n'a pas disparu : SecureVault lui applique l'attribut « caché » pour plus de discrétion. Dans l'Explorateur, activez l'affichage des éléments masqués (onglet Affichage → Afficher → Éléments masqués) pour le retrouver, ou déverrouillez-le directement via le fichier .securevault compagnon (qui reste visible, lui).

Mon antivirus bloque ou signale SecureVault, est-ce normal ?

Oui, c'est un faux positif courant : SecureVault modifie les permissions NTFS et les attributs de fichiers, un comportement que certains antivirus surveillent de près par précaution. Ajoutez une exception pour securevault.exe dans votre antivirus si besoin.
